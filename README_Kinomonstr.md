# Kinomonstr — Movie Platform

A responsive movie discovery platform built with vanilla HTML5, CSS3 and JavaScript, integrating external media resources for trailers and ratings, with a focus on modular, maintainable component structure.

🔗 **Live demo:** [blackaslife.github.io/Kinomonstr](https://blackaslife.github.io/Kinomonstr/)
📦 **Source code:** this repository

## Overview

Kinomonstr presents movie information (trailers, ratings) in a clean, mobile-friendly layout, built to make future feature additions straightforward through modular CSS and JavaScript.

## Features

- Responsive movie browsing interface
- Integration with external media resources for trailers and ratings
- Lightbox-style media viewing via [Glightbox](https://biati-digital.github.io/glightbox/)
- Modular, reusable CSS and JavaScript components
- Mobile-first responsive design

## Built With

- **HTML5** — semantic markup
- **CSS3** — modular, component-based styling
- **JavaScript (ES6+)** — vanilla JS interactivity
- **Glightbox** — lightbox media gallery

## What I Learned

Structuring the CSS and JavaScript into small, reusable components (rather than one large stylesheet) made it much easier to extend the site with new sections later, and taught me to think about maintainability from the start of a project rather than refactoring after the fact.

## Getting Started

Clone the repository and open `index.html` directly in a browser.

```bash
git clone https://github.com/blackaslife/Kinomonstr.git
cd Kinomonstr
open index.html
```
